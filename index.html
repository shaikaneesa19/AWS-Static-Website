Storage

Amazon S3

Amazon Simple Storage Service (S3) is an object storage service offering industry-leading scalability, data availability, security, and performance. It stores data as objects within buckets and is the foundation of static website hosting on AWS.

  • ✓
    Static Website Hosting Serve HTML, CSS, JS, and media directly from an S3 bucket configured as a website endpoint.
  • ✓
    99.999999999 % Durability S3 automatically replicates data across multiple facilities within a region.
  • ✓
    Versioning & Lifecycle Protect against accidental deletes and automate transitions to cheaper storage classes.
  • ✓
    Bucket Policies & ACLs Fine-grained access control keeps your data private — OAC restricts access to CloudFront only.

CDN

AWS CloudFront

Amazon CloudFront is a fast Content Delivery Network (CDN) that securely delivers data, videos, applications, and APIs to customers globally with low latency and high transfer speeds. It integrates natively with S3 to serve your static website from the nearest edge location.

  • ✓
    450 + Edge Locations Content is cached at points of presence worldwide, dramatically reducing load times.
  • ✓
    HTTPS & TLS 1.3 Free SSL/TLS certificates via AWS Certificate Manager for end-to-end encryption.
  • ✓
    Origin Access Control OAC ensures only CloudFront can access your S3 bucket — the bucket stays fully private.
  • ✓
    DDoS Protection Built-in AWS Shield Standard automatically mitigates common network and transport layer attacks.
